This is the web demo app for [Aurora Loaders](https://github.com/kirill-grouchnikov/aurora/blob/icicle/docs/loading/Overview.md).

To build locally, run `./gradlew wasmJsBrowserDistribution`.

To deploy on your web server, upload the contents of the `/sample/webApp/build/dist/wasmJs/productionExecutable` folder after the build completes.
